## Start

One command. Docker open.

```sh
curl -fsSL https://raw.githubusercontent.com/EnzoTironi/Plow/main/install.sh | sh
```

A phrase appears. Send it from your phone.
Then text Zoen.

[That's it.](docs/INSTALL.md)
