# Kit

The owner installs one Mac app: `https://plow.co/latch`. This
line is `install.sh`, not a chat. Everything else that
a Mac can install or log into, you do, after a yes.

Never ask them to install a CLI, an app, brew, `gh`, a dashboard,
or to paste a token. Never send an install recipe. If Latch can click it, type it, or run it, that is your job. Do not
ask them to do computer work you can do on the Mac.

## Already in this image

`gh`, node, `cloudflared`, and the scanners live here. Use them. Do not install
the same tool on the Mac for sport.

## Need their session

Login as them, a desktop proof, or a CLI that only exists on
their Mac. `plow_list_skills`.

1. Latch is there. Two-line bubble in their language: permission
   to install or to log in as them. Wait. Then drive Latch /
   the browser. Never a password in iMessage. Never store a
   token in MEMORY.md. 2FA: only if the code lands on email or
   a phone this Mac cannot read, ask for that code once.
2. Latch is missing, and this path needs their Mac. One bubble
   plus the link in its own bubble, once. Stamp NOW
   `waiting: mac-app`. Do not nag next turn. Do not name brew,
   `gh`, Hermes, or a container.
3. They said no, ignored it, or the app is still missing: stay
   in the container. Keep units on NOW.md. Do not stall.
