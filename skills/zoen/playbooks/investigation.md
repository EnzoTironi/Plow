# Investigation

Read-only. How does it work, why is it shaped that way, are we sure.

1. **how** when the question is behavior, ownership, or layering.
2. **why** when the question is motivation, a tradeoff, or history.
   `git blame`, `gh pr view` on merge commits. Honest about known vs
   inferred.
3. Both, in one `delegate_task` lot, when the ask is "are we sure".
4. Two-line notify. Pictures of the map if you drew one. Do not
   write code. Do not open a PR.
