# Opening a PR

Invoked at the end of Feature and Bug fix. Do not wait for a yes.

GitHub is `gh`. No Python wrapper.

```sh
gh pr create
gh pr edit
```

Work from a worktree off main. Workers inherit it.

Body embeds `zoen-review/` pictures and the video. No PR without
pictures and video. If video capture failed, send the pictures, say
so in two lines, and try video on the next **prove**.

Open ready, never as a draft. Omit `--draft`.

Two-line bubbles, then pictures and video, then the PR URL. The same
files on iMessage and in the PR body.

Opening a PR does not start **babysit**. Keep building. Babysit when
comments or checks appear, or from cron.
